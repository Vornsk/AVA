# 02 · 프로젝트 (Projects)

> 사이드바 **작업공간 > 프로젝트** · 소스 `frontend/src/pages/Projects.tsx` · 생성/가져오기·인증정보·전용 프록시는 **리더 전용**

진단 대상(프로젝트)을 생성·전환·관리하는 페이지입니다. 활성 프로젝트를 바꾸면 스코프·점검항목이
그 프로젝트로 바뀌고, 취약점·커버리지·리포트·이행점검이 해당 프로젝트 기준으로 표시됩니다.
멀티테넌시(§5.1)·멤버 ACL·암호화 인증정보의 관리 지점입니다.

## 화면 구성

각 프로젝트 카드에 다음이 포함됩니다.

- **기본 정보** — 이름·ID·`active` 배지·findings 수, 대상 URL, 스코프·스킴 태그, 생성일
- **활성 전환** — `Activate` 버튼으로 공유 프록시(:8080)·화면 기준을 이 프로젝트로 전환
- **내보내기/가져오기** — 프로젝트 파일(`.cgpkg` 등 DRM 비간섭 확장자)로 export(`Download`) /
  import(`Import`, 리더)
- **전용 프록시 (TenantSection)** — 프로젝트 전용 프록시를 별도 포트에 시작/중지. 실행 중이면
  `127.0.0.1:<port>`·요청/캡처 수 표시. 두 프로젝트를 **동시에 격리 진단** 가능(교차오염 0)
- **멤버 (MembersSection)** — 소유자 + 멤버 목록. 리더가 멤버 추가/제거(프로젝트별 ACL, FR-1.4)
- **인증정보 (CredentialsSection)** — 쿠키/헤더 인증정보. **AES-256-GCM으로 서버에 암호화 저장**,
  평문은 저장/전송되지 않음. 마스킹 요약 표시(cookie/hdr/id 배지), 리더만 설정·변경

**New Project 폼** — 대상명·스코프(쉼표 구분)·스킴 선택(주요정보통신기반시설/전자금융/모바일)

## 주요 액션 → API

| 액션 | 엔드포인트 | 권한 |
|---|---|---|
| 프로젝트 생성 | `POST /api/projects` | 리더 |
| 활성 전환 | `POST /api/activate-project` | — |
| 내보내기/가져오기 | `GET /api/projects/{id}/bundle` · `POST /api/import-bundle` | 리더 |
| 전용 프록시 시작/중지 | `POST /api/tenants/{id}/start` · `/stop` | 리더 |
| 멤버 추가/제거 | `POST /api/projects/{id}/members` · `/members/remove` | 리더 |
| 인증정보 설정 | `POST /api/project-credentials?id=` (암호화) | 리더 |

조회: `/api/projects` · `/api/active-project` · `/api/tenants` · `/api/project-credentials` · `/api/users`
