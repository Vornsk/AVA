# 06 · 점검 커버리지 (Coverage)

> 사이드바 **결과 > 커버리지** · 소스 `frontend/src/pages/Coverage.tsx` · 모든 역할 접근

취약점뿐 아니라 **선택 스킴의 전 점검항목에 대한 수행 결과**(양호·취약·미점검·미지원)를 보여주는
페이지입니다. 규제 제출용 "점검결과표"의 화면 버전으로, FR-4.3·§6에 대응합니다.

## 화면 구성

- **전체 준수 태세** — 모든 항목의 상태 분포 세그먼트 바 + 건수 범례. `점검결과표 .xlsx` 다운로드.
  취약·미점검(=갭)을 먼저 확인하도록 안내
- **스킴별 블록 (SchemeBlock)** — 스킴(주요정보통신기반시설/전자금융/모바일)마다:
  - 헤더: 전체 항목 수, `취약 N` · `자동가능 M/N` 배지
  - 상태 분포 바
  - 항목 테이블: 항목 ID(위험도 `R`) · 취약점명 · 매핑 탐지기 · findings 수 · 상태.
    **취약·미점검 항목을 위로 정렬**, 취약 행은 강조

## 상태 의미

| 상태 | 뜻 |
|---|---|
| 취약 | 해당 항목에서 finding 도출 |
| 양호 | 탐지기 수행했으나 미도출 |
| 미점검 | 자동 가능하나 아직 미수행 |
| 미지원(도구없음/수동) | 자동화 불가 — 수동 점검 대상 |

## 3계층 매핑 (§6)

Detector(코드) → VulnDef(정의, 중복제거) → CheckItem(스킴별 규제항목). 커버리지는 이 매핑을 따라
스킴별로 집계됩니다. 항목표 인코딩 현황·수정 주의는 [00-아키텍처 §4](00-아키텍처.md) 참고.

## 뒷단 연결
`GET /api/coverage` (5초 폴링) · `GET /coverage.xlsx` (점검결과표 다운로드)
