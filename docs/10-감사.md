# 10 · 감사 로그 (Audit)

> 사이드바 **인텔리전스 > 감사** · 소스 `frontend/src/pages/Audit.tsx` · 모든 역할 조회

**누가·언제·무엇을** 했는지 모든 변경 이력을 남기는 페이지입니다. 규제 제출용 증적으로
CSV 내보내기를 지원합니다. FR-1.4(RBAC·감사)에 대응합니다.

## 화면 구성

- **요약 + 필터** — 총 건수, **거부(denied) 건수** 강조, 결과 필터(전체/성공/거부),
  행위(action) 드롭다운, 사용자·대상·상세 검색
- **로그 테이블** — Time · User · Role · Action · Target · Result · Detail. **거부 항목은 붉게 강조**
- **CSV 내보내기** — `CSV 내보내기` 버튼(UTF-8 BOM, 한글 안전)

## 무엇이 기록되나
프로젝트 생성·전환, 인증정보 설정, 스캔 시작·일시정지·취소, 룰 채택, 사용자 생성·삭제·비번 재설정,
finding 전체 초기화, 로그인 시퀀스 저장 등 **상태를 바꾸는 행위**와 **권한 거부(denied)**가 남습니다.

## 뒷단 연결
`GET /api/audit` (4초 폴링) · `GET /audit.csv` (UTF-8 BOM, encoding/csv)
