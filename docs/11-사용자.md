# 11 · 사용자 관리 (Users)

> 사이드바 **관리 > 사용자** · 소스 `frontend/src/pages/Users.tsx` · 생성·삭제·비번 재설정은 `user:manage` (리더 전용)

계정을 조회하고, 리더가 계정을 생성·삭제·비밀번호 재설정하는 페이지입니다. FR-1.4(RBAC)에 대응합니다.

## 역할(RBAC)

| 역할 | 표기 | 권한 |
|---|---|---|
| leader | 리더 | 관리·승인 — 프로젝트/사용자 관리, 인증정보 설정, 룰 채택, finding 초기화 등 |
| analyst | 수행원 | 진단 수행 — 크롤·스캔·이행점검·상태 전이 |

## 화면 구성

- **계정 생성 (리더만 노출)** — 이름·역할(수행원/리더)·비밀번호(6자 이상). 비밀번호는 **bcrypt로만
  저장**, 응답에 노출되지 않음
- **사용자 목록** — ID·이름(역할 아이콘·`(나)` 표시)·역할 배지. 리더에게는 행별 작업 버튼:
  - **비번** — 비밀번호 재설정(6자 이상)
  - **삭제** — 계정 삭제. **자기 자신·마지막 리더는 삭제 불가**(버튼 disabled)

## 가드레일
- 이름 중복 → 409 · 비번 6자 미만/잘못된 역할 → 400
- 자기 자신 삭제 → 400 · 마지막 리더 삭제 → 409
- 수행원이 생성 시도 → 403

## 주요 액션 → API

| 액션 | 엔드포인트 | 권한 |
|---|---|---|
| 계정 생성 | `POST /api/users` | 리더, 감사 기록 |
| 비번 재설정 | `POST /api/users/{id}/password` | 리더 |
| 계정 삭제 | `POST /api/users/{id}/delete` | 리더 |

조회: `GET /api/users` · `GET /api/me`

## 데모 계정
`leader / leader123` (리더) · `analyst / analyst123` (수행원).
개발용 `auth_disabled: true`(local.config.yaml)면 로그인 우회 — **운영 금지**.
