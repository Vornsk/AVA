# 01 · 개요 (Project Workspace)

> 사이드바 **작업공간 > 개요** · 소스 `frontend/src/pages/Overview.tsx` · 모든 역할 접근

활성 프로젝트의 진단 현황을 **한 화면 요약**으로 보여주는 대시보드입니다. 별도 액션은 없고,
4초 주기 폴링으로 실시간 상태를 표시합니다.

## 화면 구성

**좌측 (2/3)**
- **프로젝트 헤더** — 활성 프로젝트명·ID·`Live Assessment` 배지, 대상 URL/스킴, LLM 프로바이더,
  생성일·프로젝트 수. 하단에 요약 지표 4개:
  - `Scope` (호스트 수) · `Attack surface` (엔드포인트 수) · `Findings` (도출 수) ·
    `Risk profile` (high/medium/low — 색상 표시)
- **Recent Scan Runs** — 최근 스캔 실행 6건(ID·탐지기·상태·진행률·findings). `View all`로
  [스캔](04-스캔.md) 페이지 이동

**우측 (1/3)**
- **Configuration Topology** — 설정 3계층 로드 상태(Shared 점검항목표 / Project 스코프·룰 / Local PC·LLM)
- **CA Certificate** — OS 신뢰 저장소에 자체 CA가 신뢰됐는지(Trusted/Untrusted), 모바일 에뮬레이터 상태
- **Guardrails** — Safe mode On/Off, 사용 가능 탐지기 수

## 뒷단 연결

`/api/stats` · `/api/scanruns` · `/api/active-project` · `/api/projects` (모두 GET, 폴링)
