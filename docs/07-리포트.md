# 07 · 리포트 / 도출리스트 (Report)

> 사이드바 **결과 > 리포트** · 소스 `frontend/src/pages/Report.tsx` · 모든 역할 접근

규제 제출용 **산출물을 내보내고 미리보는** 페이지입니다. 표준 엑셀 양식(도출리스트 11컬럼)과
증적을 한곳에서 확인합니다. §5.4·FR-4.2에 대응합니다.

## 화면 구성

- **산출물 허브** — 두 산출물 다운로드 버튼:
  - `도출리스트 .xlsx` — 취약점 목록(11컬럼) **+ 증적 시트**(재현요청·증명응답)
  - `점검결과표 .xlsx` — 전 항목 수행결과(→ [커버리지](06-커버리지.md)와 동일 산출물)
  - 요약: 총 도출 건수 · 증적 건수 · 취약점 유형별 칩(심각도 색상)
- **도출리스트 미리보기** — 취약점 **유형별 그룹**(심각도 높은 유형 먼저), 유형마다 표
  (NO·대상·발견 URL·파라미터·설명·비고)
- **증적 미리보기 (FR-4.2)** — 각 발견의 재현 요청·증명 응답(민감정보 마스킹)을 접이식으로.
  **다운로드 없이 화면에서 검토** 가능

## 산출물 양식 메모
- 도출리스트 xlsx는 **11컬럼 표준 양식**을 유지합니다("사용 구문" 컬럼은 재현요청 우선).
- 증적은 도출리스트 xlsx의 **별도 시트**로 함께 들어갑니다.

## 뒷단 연결
`GET /api/report` · `GET /api/evidence` (미리보기, 5초 폴링) · `GET /report.xlsx` · `GET /coverage.xlsx` (다운로드)
